## 🚀 如何使用與日常更新？

1. **一鍵切換三大閱讀頻道**（位於報頭下方與手機底部導覽列）：
   - **📖 專題深度閱讀**：直接閱讀《台灣電表種類與「二段式 vs. 三段式」時間電價全貌圖解》（內建 3 張生成插畫＋24小時時段切換器＋LCD 電表模擬器＋10秒電費試算器），或從左側切換其他專題與影片。
   - **📚 知識進化卡片庫**：以《世界大事日報》經典雙欄報紙卡片牆格式瀏覽所有知識專題，並支援分類、格式篩選與關鍵字搜尋。
   - **🌍 世界大事日報**：100% 保留原有期數下拉選單、五大國際分類、好壞消息篩選、中英標題對照、暖金螢光筆重點速覽抽屜與已讀打卡！
2. **一鍵複製 AI 更新提示詞**：
   - 點擊網頁右上角 **「🤖 AI 更新提示詞」** 按鈕，即可一鍵複製：
     - **提示詞 ①**：請 AI 搜尋今日全球大國新聞並寫入 `news_data.js`。
     - **提示詞 ②**：請 AI 讀取 `inbox_待整理資料/` 或針對您想學的新主題撰寫圖文科普並寫入 `data/articles.js`。
